
# Student Task Manager

A simple task management application built using
Python Flask, SQLite and Docker.

## Technologies Used
- Python Flask
- SQLite Database
- Docker
- Docker Compose
- GitHub

## Features
- Add new tasks
- View saved tasks
- Delete tasks
- Persistent database storage

## Run the Project

Clone the repository:

git clone YOUR_REPOSITORY_URL

Go inside the folder:

cd Student-Task-Manager

Start the application:

docker compose up --build -d

Open in browser:

http://localhost:5000

## Docker Commands

docker compose ps
docker compose logs
docker compose down
